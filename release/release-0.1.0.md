# 转绘短剧工厂 v0.1.0

首个版本：以 **React Flow** 无限画布承载**转绘短剧分镜**的天枢 TPI 插件。

## 亮点

- **深黑画布**：深黑底 + 暖橙强调色，镜头卡像胶片格。
- **本地服务 + 浏览器**：插件 headless，画布以 `http://127.0.0.1:43187` 提供，浏览器打开即用。
- **分镜即节点**：每个镜头是一张沙箱 iframe 渲染的分镜卡，支持竖屏 9:16 / 横屏 16:9 / 方形 1:1。
- **编排**：镜头复制、删除、右键重命名、镜头间连线（表达分镜顺序）。

## 工具

| 工具 | 用途 |
|---|---|
| `redraw_open` | 启动/复用本地画布服务，返回浏览器 URL |
| `redraw_upsert_shot` | 新增镜头，或更新已有镜头（内容 / 标题 / 位置 / 尺寸 / 画幅） |
| `redraw_get_state` | 读取镜头列表、连线、用户当前选中项、画布 URL |
| `redraw_arrange` | 删除 / 复制镜头、连线 / 取消连线 |

## 数据与安装

- 项目数据：`<工作区>/.tianshu-redraw/`（`project.json` + `shots/<id>.html`），可版本化。
- 安装：天枢「插件中心 → 社区插件 → 从其他来源安装」，填本仓库 Git URL 或本地绝对路径。
  仓库根即插件根（`tianshu.plugin.json` 在根目录）。安装后需**新建会话**生效。

## 说明

- 分镜卡必须自包含：外链（CDN / 字体 / 图片）与相对路径会被画布 CSP 拦截。
